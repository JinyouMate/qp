# 汽配知识局 · 设计系统

> 配置文件：`tailwind.config.ts` + `app/globals.css`
> 原则：暖、轻、可信。不做冷工业风，不做花哨电商风。

---

## 1. 色彩

### 1.1 品牌色

| 角色 | 名称 | 色值 | Tailwind 类名 | 用途 |
|---|---|---|---|---|
| **主色** | 深绿 | `#1F6F4A` | `bg-brand-green` / `text-primary` | 导航、标题强调、信任条、成功态 |
| 主色辅助 | 中绿 | `#2F8F5B` | `bg-brand-green-mid` | hover、次级强调 |
| 主色浅 | 浅绿 | `#E5F0E9` | `bg-brand-green-soft` | 徽章底、提示块底 |
| **行动色** | 砖红 | `#C44536` | `bg-brand-red` / `bg-destructive` | **主 CTA**、价格、预约咨询 |
| 砖红浅 | 浅红 | `#F8E9E5` | `bg-brand-red-soft` | 警示底、价格标签底 |
| **强调色** | 暖橙 | `#E07A3F` | `bg-brand-orange` | 「去第三方购买」、阶梯强调、AI 入口 |
| 暖橙浅 | 浅橙 | `#FBEFE2` | `bg-brand-orange-soft` | 强调块底、徽章底 |
| 辅助 | 米白 | `#F7F4EF` | `bg-brand-cream` | **页面背景**、区块交替底 |
| 辅助 | 浅灰 | `#E8E5DF` | `bg-brand-gray` | 分隔线、禁用态、骨架屏 |
| 文字 | 暖炭 | `#3A332B` | `text-foreground` | 正文（**不用纯黑**） |
| 次要文字 | 暖灰 | `#857C6F` | `text-muted-foreground` | 说明、元信息 |
| 卡片 | 近白暖 | `#FCFAF6` | `bg-card` | 卡片底（**不用纯白**） |

### 1.2 语义变量（HSL，供 `bg-primary` 等 shadcn 类使用）

```
--background  38 33% 95%    --foreground      32 15% 20%
--card        42 50% 98%    --card-foreground 32 15% 20%
--primary    152 56% 28%    --primary-foreground 38 33% 97%
--secondary  148 30% 92%    --secondary-foreground 152 50% 24%
--muted       40 16% 93%    --muted-foreground 36 9% 48%
--accent      26 85% 95%    --accent-foreground 24 72% 42%
--destructive  6 57% 49%    --destructive-foreground 38 33% 97%
--border      40 22% 87%    --ring 152 56% 28%
```

### 1.3 使用规则
- **一屏最多两个强色**：绿打底 + 红做行动点，橙只用于需要"跳出去"的动作（第三方购买）。
- 禁止大面积纯黑 `#000`、纯白 `#FFF`、金、银。白只用 `#FCFAF6` 卡片色。
- 价格一律用砖红 `text-brand-red`，形成"看到红字=钱"的稳定联想。

## 2. 字体

```ts
fontFamily.sans = [
  "var(--font-inter)",      // 英文/数字：Inter（next/font）
  "var(--font-noto-sc)",    // 中文：Noto Sans SC（next/font）
  "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "system-ui", "sans-serif"
]
```

| 层级 | 尺寸（移动 / 桌面） | 字重 | 行高 |
|---|---|---|---|
| H1 Hero | 30–34 / 44–52px | 700 | 1.2 |
| H2 区块标题 | 22–24 / 30–34px | 700 | 1.3 |
| H3 卡片标题 | 16–17 / 18px | 700 | 1.4 |
| 正文 | 14–15 / 15–16px | 400 | 1.75 |
| 说明/元信息 | 12–13px | 400 | 1.6 |
| 按钮 | 14–15px | 600 | — |
| 标签徽章 | 11–12px | 600 | — |

> 移动端字号不小于 12px；正文行高不低于 1.7（中文阅读需要）。

## 3. 圆角与阴影

| 元素 | 圆角 | 类名 |
|---|---|---|
| 卡片 / 弹窗 / 大容器 | **16px** | `rounded-lg` |
| 按钮 / 输入框 / 小卡 | **12px** | `rounded-md` |
| 徽章 / 图标底座 / 小标签 | **8–10px** | `rounded-sm` |
| 头像 / 圆形按钮 | 全圆 | `rounded-full` |

```
shadow-warm     0  4px 16px rgba(122, 98, 62, 0.08)   卡片常态
shadow-warm-md  0  8px 24px rgba(122, 98, 62, 0.11)   hover / 浮起
shadow-warm-lg  0 12px 32px rgba(122, 98, 62, 0.14)   弹窗 / 悬浮球 / 固定条
```
阴影一律用暖棕 `rgba(122,98,62,*)`，**不用灰色阴影**（灰阴影会显冷）。

## 4. 间距与栅格

```
.container-site   max-w-6xl（1152px）· px-4（移动）/ px-6（≥640px）· 居中
.section-pad      py-12（移动）/ py-20（≥768px）
卡片间距          gap-4（16px），区块间 gap-8 ~ gap-12
栅格              移动 1 列 · sm 2 列 · lg 3–4 列（入口卡 4 列，产品卡 3 列）
```

> **移动端优先**：所有断点默认先写移动样式，再用 `sm:` `md:` `lg:` 放大。

## 5. 组件视觉规范

### Button 变体
| 变体 | 底色 | 用途 |
|---|---|---|
| `default` | 深绿 | 通用主行动 |
| `destructive` | **砖红** | 主 CTA：领取资料 / 预约咨询 / 提交 |
| `orange` | 暖橙 | 去第三方购买（需要"跳出去"） |
| `outline` | 描边 + 米白底 | 次级：免费领取 / 了解更多 |
| `secondary` | 浅绿 | 中性操作 |
| `ghost` | 透明 | 导航、文字链 |

尺寸：`sm`（卡片内）/ `default`（页面级）。移动端按钮高度 ≥ 44px（触控区）。

### Badge 变体
`default`(绿) · `secondary`(浅绿) · `accent`(橙) · `destructive`(砖红) · `outline`(描边)
用途：层级徽章（流量层/信任层/转化层/交付层）、档位徽章、平台徽章。

### Card
`bg-card` + `rounded-lg` + `border` + `shadow-warm`，hover 升为 `shadow-warm-md`。
头部 `CardHeader`（图标 + 徽章 + 标题 + 定位），内容 `CardContent`（五要素 + CTA）。

## 6. 图标

- 库：**lucide-react**，统一线性风格，`strokeWidth = 1.5`，尺寸 16/20/24px。
- 产品图标通过 `components/site/icon.tsx` 的 `ICONS` 映射表按名取用（新增产品只需加一行）。
- 已映射：`video` `list-checks` `file-text` `book-open` `table` `folder-open` `calculator`
  `coins` `scan-search` `boxes` `graduation-cap` `book` `line-chart` `badge-check`
  `compass` `presentation` `wrench` `bot` `sparkles` `qr-code` `message-circle`

## 7. 图片方向

**要**：真实工作场景（仓库、工位、打包台）、数据截图（表格/看板，可脱敏）、课程现场照。
**不要**：假大空 stock photo、握手团队照、3D 渲染齿轮。

占位规范：未替换前用 `.figure-ph`（虚线边框 + 米白底 + 说明文字），上线前逐项替换。

## 8. 动效

| 场景 | 表现 |
|---|---|
| 卡片 hover | 阴影 `warm → warm-md`，位移 -2px，200ms ease-out |
| 按钮 | 无位移动画，仅底色加深 |
| 弹窗 | Radix 默认 fade + zoom，180ms |
| 折叠面板 | `accordion-down/up` 200ms |
| 固定留资条 | 滚过 400px 后淡入上移 |
| 页面内锚点 | `scroll-behavior: smooth` |

> 尊重 `prefers-reduced-motion`（Radix 与 Tailwind Animate 默认处理）。

---

## 9. 可访问性与移动端

- 文字对比度 ≥ 4.5:1（砖红底白字、深绿底白字均达标）
- 所有可点击元素最小触控区 44×44px
- 表单每项都有 `<Label>` 关联，错误提示用 `role="alert"`
- 移动端底部固定条留出 `env(safe-area-inset-bottom)` 安全区
- 焦点环统一 `ring-2 ring-ring`（深绿）
