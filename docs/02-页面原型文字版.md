## 17. 交互状态约定（全站统一）

| 场景 | 表现 |
|---|---|
| 表单提交中 | 按钮转圈禁用，文案「提交中…」 |
| 提交成功 | 绿色对勾 + 「加微信后回复【汽配数据】」→ 自动跳加微页 |
| 提交失败 | 红色提示条 + 重试按钮，已填内容不丢 |
| 外链点击 | 先弹拦截窗（3 个出口），放行后新窗口打开 |
| 空数据 | 明确的空态文案 + 引导动作（不用空白页） |
| 未接数据库 | 页面照常渲染兜底数据；看板明确标注「演示数据」 |
