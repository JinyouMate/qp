# 12 · 知识星球加入与交付流程

> **最终策略（不可回退）**：本项目**不接入任何原生支付**（无支付宝 / 微信支付 / 无站内收银台 / 无二维码支付页）。
> 官网只负责：展示 → 建立信任 → 留资收口 → 跳转。
> 所有产品的成交、付款、内容查阅与交付，**全部在知识星球完成**。

---

## 一、转化闭环（唯一路径）

```
产品卡 / 详情页【加入知识星球】【获取星球入口】
        │
        ▼  不直接跳转
┌───────────────────────────────────────┐
│ 留资弹窗（planet-dialog.tsx）          │
│ 「为保证服务质量，请先留下你的微信/手机号， │
│   我们将发送专属星球入口和新人资料包。」   │
│   手机/微信* · 称呼(选填) · 身份 · 同意   │
│        └─ POST /api/leads → leads 表    │
└───────────────────────────────────────┘
        │ 提交成功
        ▼
┌───────────────────────────────────────┐
│ A【复制星球链接】  复制 planet_url(+UTM) │
│ B【添加企微，领取新人礼】 展示企微二维码   │
│                                       │
│ 知识星球 APP 内搜索加入，或复制链接在    │
│ 微信中打开。付款后即可永久查阅所有 SOP   │
│ 与报告。                               │
└───────────────────────────────────────┘
```

**没有留资就没有入口**——这是唯一的收口，任何产品都不例外。

## 三、`products.planet_url`

```sql
alter table public.products add column if not exists planet_url text;
-- 约束：空值允许，填了必须是 http(s)
```

| 字段 | 语义 |
|---|---|
| `planet_url` | **知识星球专属邀请链接**（主力） |
| `third_party_url` | 老字段：第三方平台/内容入口（兼容保留） |

**优先级**：`planet_url → third_party_url → PLANET.defaultUrl → 弹窗内降级提示`。
都没配时弹窗只给【加企微】路径，**绝不跳死链**。

配置示例：

```sql
update public.products set planet_url = 'https://t.zsxq.com/xxxx'
 where slug = 'courses';

-- 查未配置的产品
select id, slug, name from public.products where coalesce(planet_url,'') = '' order by id;
```

## 四、UTM 规范

```
planet_url?utm_source=website&utm_medium=product&utm_campaign={product_id}
```

- campaign 用**产品 id**（不是 slug），与后台 `products.id` 一一对应
- 已有 query 自动用 `&` 连接，同名参数覆盖
- 实现：`withPlanetUtm(url, productId)`（`lib/utm.ts`）

## 五、落库字段（`/api/leads`）

| 字段 | 值 |
|---|---|
| `contact` | 用户填的手机号 / 微信（必填，≥5 字符） |
| `name` | 称呼（选填，默认「未填写」） |
| `role` | 身份 chips：修理厂 / 汽配商 / 平台企业 / AI公司 |
| `demand` | 由 `demandForProduct(product)` 推导 |
| `description` | `加入意向：{产品名}（{slug}）· 已下发知识星球入口与新人资料包` |
| `identity` | 归一化身份（0005 触发器自动补齐） |
| `utm_source` | 首触来源（0005 触发器自动补齐） |
| `utm` / `channel` / `source` | UTM 明细、渠道、当前页 URL |

防刷：蜜罐字段 `website` + 同 IP 限流（5 次/分钟、20 次/小时）+ zod 校验。

## 七、权限查询页 `/access`

替代原来的查单页。因为本站没有订单，页面只做三件事：

1. **在知识星球 APP 里看**：我 → 我加入的 → 汽配知识局
2. **用微信打开星球链接**：回产品页重新获取 → 粘贴到微信打开
3. **还是找不到 → 加企微客服核对**：报留资时的手机/微信，人工查星球后台

页面 `noindex`，不进 sitemap。

## 九、自测命令

```bash
npm run build
npx next start -p 3111

# 产品详情页应出现「加入知识星球」，且不出现「立即购买」
curl -s --noproxy '*' http://localhost:3111/products/courses | perl -pe 's/<!--.*?-->//g' | grep -o "加入知识星球"

# 权限页
curl -s --noproxy '*' -o /dev/null -w "%{http_code}\n" http://localhost:3111/access

# 留资接口
curl -s --noproxy '*' -X POST http://localhost:3111/api/leads \
  -H 'Content-Type: application/json' \
  -d '{"name":"李四","contact":"13900139000","role":"汽配商","demand":"课程","description":"加入意向：体系课（courses）","consent":true}'
```
