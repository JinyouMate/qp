# 汽配知识局 · 组件清单

> 两层结构：`components/ui/*`（shadcn 基础件，无业务）+ `components/site/*`（业务组件）
> 新增页面优先复用 site 组件；新增产品只需改 `lib/data.ts`，不用动组件。

## 2. 站点业务组件 `components/site/`

### 布局与全局

| 组件 | Props | 说明 |

## 5. 组件选用速查

| 我要做… | 用什么 |
|---|---|
| 新增一个内页 | `PageHero` + `SectionHeading` + 若干 `Card` + `LeadSection` + `breadcrumbSchema` |
| 新增一个产品 | 只改 `lib/data.ts`（或 Supabase `products` 表），页面自动出现 |
| 加一个站外链接 | `ExternalLink`（自动过拦截）或 `ProductCta`（产品场景） |
| 加一个埋点 | 站内链接用 `TrackedLink`；行为用 `trackEvent(name, props)` |
| 页面底部收口 | `<LeadSection title="…" desc="…" />` |
| 展示价格阶梯 | `<ProductLadder products={items} />` |

## 6. 约定（改动前请读）

1. **CTA 色不可乱用**：砖红=主转化，橙=跳第三方，绿=通用，描边=次级。
2. **所有站外链接必须过 `ThirdPartyGate`**，不允许裸 `<a href="https://...">`。
3. **所有站内跳转若要埋点用 `TrackedLink`**，不要直接 `next/link`。
4. 产品数据五要素缺一不可，缺字段会在卡片上留空，视觉立刻塌。
5. 移动端优先写样式；固定元素记得避让底部条（`bottom-24` 起）。
